# sbud

sbud manages Docker Sandboxes for AI agents. This repository holds sbud's releases and user documentation.

No release has been published yet.

## Client libraries

| Language | Package | Source |
|---|---|---|
| .NET | `Sbud` on NuGet | [sbud-dotnet](https://github.com/teaToolkit/sbud-dotnet) |
| Python 3.10 and later | `sbud` on PyPI | [sbud-python](https://github.com/teaToolkit/sbud-python) |
| Node 20 and later | `@teatoolkit/sbud` on npm | [sbud-node](https://github.com/teaToolkit/sbud-node) |

The command line, `sbud`, is in [sbud-cli](https://github.com/teaToolkit/sbud-cli).
